# Murrell2026 — Figures

This folder contains the **figure-generation notebooks** and **schematic art assets** used to produce figures for the Murrell (2026) project.

- `Figure*.md` Is a mark down file containing the rendered figures as well as a link to the **analysis notebooks** used to generate the figures.
- `Murrell_2026jpgs/` contains **schematic image files** of the FED3 homecage device and each task structure.

---

## How to use

1. Select the md file for the figure you want (ie Figure 1.md) Click on the link to open the ipynb file in google colab.
2. At the top of the page click <img width="64" height="25" alt="image" src="https://github.com/user-attachments/assets/b2403fa6-9bef-40a8-b6f7-f9bccf7b0e32" /> The analyse will run and each panel from the figure will render.
3. At the bottom of each notebook is extra information collected as part of the analysis that are not included in the figures
