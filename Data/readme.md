# Murrell2026 — Data

This folder contains the **raw behavioral data** and **derived summary tables** used in the Murrell *et al.* project. The top-level datasets are provided as zipped bundles by task (e.g., `Bandit100`, `Bandit80`, `FR1`, `PR1`). A subject key is provided to map mouse IDs to experimental metadata. :contentReference[oaicite:0]{index=0}

---

## Contents
:contentReference[oaicite:1]{index=1}

### Raw task datasets (`*.zip`)
Each zip corresponds to a behavioral paradigm/task:
- **`Bandit100.zip`** — bandit task dataset (100 condition)
- **`Bandit80.zip`** — bandit task dataset (80 condition)
- **`FR1.zip`** — fixed-ratio 1 task dataset
- **`PR1.zip`** — progressive-ratio task dataset

These are the “source-of-truth” raw exports for the paper/analysis pipeline. :contentReference[oaicite:2]{index=2}

### Subject / metadata key (`Murrell2026_Key.csv`)
`Murrell2026_Key.csv` maps each animal to core metadata fields including:

- `Mouse_ID`
- `Gene`
- `Sex`
- `FED3` (device ID)
- `FED_StartDate`
- `DOB`
- `Bandit100_weight`
- `FR1_Weight`
- `Bandit80_weight`

Use this file to join animal metadata onto either raw task files (inside the zips) or the derived summary outputs. :contentReference[oaicite:3]{index=3}

> **Note:** The CSV is formatted as comma-separated fields, but the raw view may appear as a single long line depending on how it’s rendered online. :contentReference[oaicite:4]{index=4}

### Derived summary tables (`SummaryStats/`)
`SummaryStats/` contains analysis-ready summary tables (e.g., per-mouse performance metrics and RL-model–related outputs) used for downstream statistics/plotting, including:
- task-level metric tables (e.g., `Bandit100_metrics.csv`, `Bandit80_metrics.csv`, `FR1_metrics.csv`)
- bandit comparison tables for statistical testing (e.g., `BanditComparisonForANOVA.csv`)
- RL modeling outputs (e.g., `Bandit_100_RL_modeling.csv`, `RL_df_no lapse.csv`) :contentReference[oaicite:5]{index=5}

## Typical workflow

1. **Unzip** the dataset for the task you need (`Bandit100.zip`, `FR1.zip`, etc.). :contentReference[oaicite:6]{index=6}  
2. **Load / parse** the raw files inside the zip (format depends on the export generated by the acquisition/analysis pipeline).
3. **Join metadata** from `Murrell2026_Key.csv` on `Mouse_ID` (and/or `FED3` device ID if needed). :contentReference[oaicite:7]{index=7}  
4. If you don’t need trial-level data, use the **`SummaryStats/` CSVs** directly for group stats and plots. :contentReference[oaicite:8]{index=8}
